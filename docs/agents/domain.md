# Domain Docs

## Antes de explorar

Leia:

- `CONTEXT.md` na raiz, se existir.
- `CONTEXT-MAP.md`, se existir, em vez de `CONTEXT.md`; ele aponta para os contextos relevantes.
- `docs/adr/` e quaisquer ADRs específicos do contexto que toquem a área alterada.

Se esses arquivos não existirem, prossiga silenciosamente. Não os crie antecipadamente; eles serão criados quando decisões de domínio forem resolvidas.

## Layout

Este é um repositório single-context:

- `CONTEXT.md`
- `docs/adr/`

## Vocabulário

Use os termos definidos no glossário do domínio em issues, hipóteses, nomes de testes e propostas. Não substitua termos por sinônimos explicitamente evitados.

Se um conceito necessário não estiver no glossário, trate isso como lacuna de domínio e registre para modelagem posterior.

## ADRs

Se uma proposta contradisser um ADR existente, destaque o conflito explicitamente em vez de sobrescrevê-lo silenciosamente.
